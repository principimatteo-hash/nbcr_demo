PROTOTIPO GESTIONALE NBCR
==========================
Questo è un prototipo grafico locale, NON è ancora il gestionale definitivo.

Cosa contiene:
- Homepage e navigazione
- Moduli preliminari
- Struttura grafica
- Predisposizione concettuale per QR/movimenti
- Nessun dato reale

Per provarlo:
1. Estrai lo ZIP.
2. Apri index.html con Edge/Chrome/Firefox.
3. Clicca i pulsanti e naviga tra i moduli.

Prossima fase:
- analisi dei file Access reali;
- progettazione database;
- definizione architettura compatibile con FS1/rete;
- importazione/migrazione dei dati;
- implementazione delle funzioni reali.
